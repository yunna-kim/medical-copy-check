# medical-copy-check

> 글은 **오퍼에서, 그리고 한 줄에서** 걸린다. 「무료로 드립니다」가 유인이 되고, 정보 글 끝의 「예약은 프로필 링크」 한 줄이 글 전체를 광고로 만든다.

의료인이 **블로그 · 스레드 · 인스타 · 카카오톡(채널 메시지 · 오픈채팅 소개·공지)** 에 올릴 글과 1차 전환 문구를
의료법 관점에서 검수하고 **대체안까지** 내는 Claude 스킬입니다. (2026-09 기준)

---

## 근거는 공개 자료뿐입니다

| 씁니다 | 안 씁니다 |
|---|---|
| 의료법·시행령 조문 | 각 협회 의료광고심의위원회의 **심의기준·금지 문구표** |
| 보건복지부 「건강한 의료광고, 우리가 함께 만들어요」 2판(2024.12) · 유권해석 · 보도자료 | 회원 전용 자료 |
| 대법원·헌법재판소·하급심 판례 | 커뮤니티 경험담 |
| 공정거래위원회 추천·보증 심사지침 · 정보통신망법 · AI기본법 | 마케팅 대행사 블로그 |

그래서 이 스킬은 **「법에 걸리는가」** 까지만 말합니다. 심의기준은 법령보다 엄격할 수 있으므로(복지부 2판 p.39),
**심의를 낼 글이면 소속 협회의 기준을 따로 확인하세요.** 원문 파일은 넣지 않고 주소만 `references/sources.md` 에 적었습니다.

## 설치

- **Claude Code** — `medical-copy-check` 폴더를 `~/.claude/skills/` 에 복사합니다.
- **claude.ai** — 폴더를 zip 으로 묶어(맨 위에 `medical-copy-check/` 폴더 하나가 오도록) 설정 → 스킬 → 스킬 업로드에 올립니다.
  윈도우 기본 압축(Compress-Archive)으로 만든 zip 은 거부될 수 있습니다. 7-Zip 이나 `zip -r` 을 쓰세요.

## 이 스킬이 지키는 것

- **법률 자문이 아니다.** 명백한 것만 걸러내고, 최종 판단은 보건소·심의위원회·법률 전문가에게 넘긴다
- **「안 된다」로 끝내지 않는다.** 지적마다 대체안 두 개
- **과잉 검열하지 않는다.** 정보 글까지 빨간불을 켜면 스킬이 버려진다
- **문구를 창작하지 않는다.** 사용자가 준 문장을 고칠 뿐
- **모르는 것을 아는 척하지 않는다.** 유권해석이 없는 채널은 「없다」고 적는다
