# 대체 표현 사전

> **이 스킬의 값어치는 여기 있다.** 「안 된다」로 끝나는 검수는 두 번 쓰이지 않는다.
> 표를 그대로 갖다 붙이지 말고, **사용자의 원문 결을 살려** 두 개를 만든다.

## 쓰는 법

지적 하나당 **두 개**를 낸다.

| | 어떤 것 |
|---|---|
| **A · 안전한 쪽** | 조항에서 확실히 벗어난다. 대신 세기가 준다 |
| **B · 세기를 살린 쪽** | 원문의 힘을 최대한 남긴다. 다만 **왜 이건 괜찮은지** 근거를 붙인다 |

**원문의 목적을 바꾸면 안 된다.** 「무료」를 지우라는 게 아니라 **금액 비교**를 지우는 것이다.

---

## 1. 값어치 — 금액을 지우고 다른 것으로

**금액 참조점은 유인이 된다.** 값어치를 **금액이 아닌 축**으로 옮긴다.

| 옮길 축 | 예 |
|---|---|
| **분량** | 「A4 12장 분량」 「15문항」 「5통에 나눠서」 |
| **시간** | 「진료실에서 30분씩 하던 설명」 「3분이면 끝납니다」 |
| **밀도** | 「평소에 다 못 드리던 이야기를 처음부터 끝까지」 |
| **희소** | 「이번 주에 오신 분들께만」 「선착순 20명」 (수량 한정은 유인이 아니다) |
| **맥락** | 「블로그를 여는 기념으로」 「4주가 지나면 자동으로 끝납니다」 |
| **목업** | 리포트 표지·목차 이미지 한 장. **보여주는 것이 값을 말하는 것보다 세다** |

| 🔴 이렇게 말고 | ✅ 이렇게 |
|---|---|
| 「20만원 상당 리포트 무료」 | 「진료실에서 30분씩 하던 설명을 그대로 담았습니다」 |
| 「정가 5만원 → 0원」 | 「이번 주에 오신 분들께만 드립니다」 |
| 「첫 상담 50% 할인」 | (할인은 대체 불가. **오퍼 자체를 바꾼다** — 자료·점검·안내로) |

---

## 2. 효과 — 단정을 여지로

**핵심은 어미다.** 「~됩니다」를 「~할 수 있습니다」로 바꾸면 대부분 풀린다.

| 🔴 | ✅ |
|---|---|
| 「불면이 치료됩니다」 | 「잠드는 시각이 앞당겨지는 경우가 많습니다」 |
| 「4주면 좋아집니다」 | 「4주 동안 무엇을 볼지 함께 정합니다」 |
| 「완치」 「보장」 | (대체 불가. **지운다**) |
| 「부작용 없이」 | 「지금 드시는 약은 그대로 두고, 순서만 봅니다」 |
| 「반드시 달라집니다」 | 「사람마다 다릅니다. 다만 순서를 바꾸면 대개…」 |
| 「효과가 있습니다」 | 「효과를 보고한 연구가 있습니다」 (+ 출처) |

### 기간을 쓰고 싶을 때

**「4주면 낫는다」는 안 되고, 「4주 동안 함께 본다」는 된다.**
기간을 **결과의 약속**이 아니라 **프로그램의 길이**로 쓰면 통과한다.

| 🔴 | ✅ |
|---|---|
| 「4주 만에 잠들게 됩니다」 | 「4주 동안 주차별로 하나씩 보내드립니다」 |
| 「2주면 피로가 사라집니다」 | 「2주차에는 몸이 먼저 반응하는 경우가 많습니다」 |

---

## 3. 경험담 — 사람에서 기전으로

**개인의 결과담을 일반론으로 옮긴다.** 이게 유일한 길이다.

| 🔴 | ✅ |
|---|---|
| 「40대 여성분이 2주 만에 잠들게 되셨어요」 | 「잠드는 시각보다 **일어나는 시각**을 먼저 고정하면 리듬이 앞당겨집니다」 |
| 「후기 캡처 이미지」 | 「이런 질문을 자주 받습니다」 + 일반적인 답 |
| 「○○명이 좋아졌습니다」 | 「진료실에서 가장 자주 듣는 이야기는 …입니다」 |

> **「진료실에서 자주 듣는 말」는 통과한다.** 결과담이 아니라 **질문의 빈도**를 말하는 것이기 때문이다.
> 「진료실에서 자주 좋아지십니다」는 걸린다.

---

## 4. 과장 — 순위에서 성격으로

| 🔴 | ✅ |
|---|---|
| 「국내 최고」 「유일한」 | 「제가 진료에서 쓰는 방식은…」 |
| 「양약보다 근본적」 | 「약을 그대로 두고 생활 쪽을 봅니다」 |
| 「95%가 만족」 | (근거가 없으면 **지운다**. 있으면 출처를 붙인다) |

**남과 비교하지 말고 내 성격을 말한다.** 비교 없이도 차별점은 전해진다.

---

## 5. 붙이면 안전해지는 문장

**있으면 ✅ 로 적고, 없으면 🟡 로 권한다.** 짧을수록 실제로 붙는다.

```
이 자료는 일반적인 건강 정보이며, 진단이나 처방, 진료를 대신하지 않습니다.
증상이 이어지거나 심해지면 의료기관에서 진료받으시길 권합니다.
```

```
복용 중인 약을 이 자료를 근거로 바꾸거나 끊지 마시고,
처방해주신 선생님과 상의해주세요.
```

```
개별 상담은 드리지 못합니다. 그건 진료실에서 뵙는 게 맞습니다.
```

> 마지막 문장은 **오픈채팅방·카카오 채널·DM 자동응답에 특히 중요하다.**
> 채널을 열면 증상 상담이 들어오는데, 이 한 줄이 미리 막는다.

---

## 6. 자주 나오는 통짜 문구 — 그대로 쓸 수 있게

### 오퍼 (1차 전환)

```
진료실에서만 하던 이야기를, 이번 주에 오신 분들께 그대로 드립니다.
3분이면 끝나는 자가 점검을 하시면, 어디부터 시작하면 되는지 정리해 보내드려요.
```

### 캐러셀 마지막 장 · DM 자동응답

```
댓글에 「{키워드}」 남겨주시면 자료를 보내드립니다.
일반적인 생활 관리 자료이고, 진단이나 처방이 아닙니다.
```

### 오픈채팅방 · 채널 소개

```
식사 · 수면 · 생체리듬에 관한 생활 관리 정보를 한 달에 한 번쯤 보내드립니다.
공지만 올라오고 대화는 없는 방입니다.
개인 진료 상담은 받지 않습니다.
```

### 신청 완료 화면

```
신청해주셔서 고맙습니다. 오늘 안에 메일로 보내드릴게요.
증상이 급하시면 기다리지 마시고 가까운 의료기관에서 진료받으세요.
```
