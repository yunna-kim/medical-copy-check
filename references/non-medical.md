# 의료인이 아닐 때

> **STEP 0 에서 「의료인이 아니다」가 나오면 이 문서 기준으로 본다.**
> 적용되는 법이 통째로 다르다. 의료법 조문을 그대로 들이대면 틀린 검수가 된다.

## 무엇이 달라지나

| | 의료인 | **비의료인** |
|---|---|---|
| 「치료」 표현 | 조건부 가능 (효과 단정이 문제) | **거의 무조건 위험** — 의료행위로 읽힌다 |
| 걸리는 법 | 의료법 제27조·제56조·제57조 | **의료법 제27조 제1항**(무면허) · **식품표시광고법 제8조** · 표시광고법 |
| 사전심의 | 매체에 따라 대상 | 대상 아님 |
| 자격 표시 | 전문의 등 **사실 표기 가능** | **자격이 없으면 있는 것처럼 보이게 하면 안 된다** |

## L7 · 무면허 의료행위 오인 — 의료법 제27조 제1항

> 의료인이 아니면 **누구든지 의료행위를 할 수 없다.**

문제는 **실제로 하지 않아도** 「하는 것처럼 보이면」 걸린다는 점이다.

### 🔴 걸리는 것

| 표현 | 왜 |
|---|---|
| **「치료」 「완치」 「교정」 「시술」** | 의료행위를 지칭하는 말이다 |
| **「진단」 「검사해 드립니다」** | 진단은 의료행위다. **「자가 점검」 「체크리스트」로 바꾼다** |
| 「○○병에 좋습니다」 | 질병에 대한 효능 표방 |
| 「병원 안 가도 됩니다」 | 진료를 대체한다는 주장 |
| 「원장」 「닥터」 「한의학 박사」 등 **오인 호칭** | 자격이 없으면 쓰지 않는다 |
| 흰 가운 · 청진기 · 병원 배경 이미지 | **이미지도 오인을 만든다** |

### ✅ 쓸 수 있는 것

「관리」 「도움」 「습관」 「루틴」 「컨디션」 「자가 점검」 「기록」 「코칭」
**「의료 행위가 아닙니다」를 명시하면 더 안전해진다.**

```
이 자료는 생활 습관에 관한 일반 정보이며, 의료 행위나 진단이 아닙니다.
질환이 의심되면 의료기관에서 진료받으시길 권합니다.
```

## L8 · 식품 · 건강기능식품 — 식품표시광고법 제8조

건강식품·보조제·차·즙 같은 것을 다루면 여기가 핵심이다.

### 🔴 걸리는 것

- **질병의 예방·치료에 효능이 있다는 표시·광고**
  「불면증에 좋습니다」 「관절염 치료」 「혈압을 낮춥니다」
- 건강기능식품이 **아닌데** 건강기능식품처럼 보이게 하는 것
- **의약품으로 오인**하게 하는 표현 — 「복용」 「처방」 「효능」
- 소비자 **체험기**를 효능의 근거로 쓰는 것 (의료와 같은 구조다)
- 「부작용 없는」 「천연이라 안전한」

### 인정받은 기능성만 쓸 수 있다

건강기능식품은 **식약처가 인정한 기능성 문구**만 쓸 수 있다.
그 문구를 벗어나 풀어 쓰면 걸린다.

| 🔴 | ✅ (인정 문구 범위 안) |
|---|---|
| 「불면증이 낫습니다」 | 「수면의 질 개선에 도움을 줄 수 있음」 |
| 「면역력을 높여 병을 막습니다」 | 「면역 기능에 도움을 줄 수 있음」 |

> **인정 문구인지 확실치 않으면 🟡 로 두고 「식약처 인정 문구인지 확인 필요」라고 적는다.**
> 이 스킬은 인정 문구 목록을 갖고 있지 않다.

## L9 · 자격 · 경력 표시

### 🔴

- 없는 자격을 있는 것처럼 (「○○협회 인증」이 실체 없는 경우)
- **민간자격을 국가자격처럼** 보이게
- 「전문가」를 **자격 표시처럼** 쓰는 것

### ✅

- 실제 경력·이력의 **사실 서술** — 「10년간 ○○을 해왔습니다」
- 민간자격은 **발급처를 함께** — 「(사)○○협회 발급」

## 비의료인에게 자주 나오는 대체

| 🔴 | ✅ |
|---|---|
| 「불면 치료 프로그램」 | 「수면 습관 관리 프로그램」 |
| 「무료 진단」 | 「무료 자가 점검」 |
| 「○○질환 개선」 | 「○○로 불편하신 분들의 생활 관리」 |
| 「닥터 ○○의」 | 「○○ 코치의」 |
| 「처방해 드립니다」 | 「함께 정합니다」 |
| 후기 캡처 | 「이런 질문을 자주 받습니다」 |

## 판정할 때 지킬 것

1. **의료법 조문을 그대로 인용하지 않는다.** 비의료인에겐 제56조가 아니라 **제27조 제1항**과 표시광고법이다
2. 「치료」류 단어는 **효과 단정이 아니어도** 🔴 다. 단어 자체가 의료행위를 지칭한다
3. **이미지도 본다.** 가운·청진기·병원 배경은 텍스트만큼 강하게 오인을 만든다
4. 식품이면 **인정 문구인지**를 반드시 🟡 로 남긴다 — 이 스킬은 목록을 갖고 있지 않다
