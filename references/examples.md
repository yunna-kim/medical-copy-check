# 검수 예시

> 톤이 흔들릴 때 본다. **판정의 세기**와 **대체안의 결**을 여기에 맞춘다.

---

## 예시 1 · 의료인 · 랜딩 오퍼

### 받은 문구

```
[블로그 개설 기념] 20만원 상당의 맞춤 회복 리포트를 무료로 드립니다
4주면 불면이 치료됩니다. 선착순 20명 특별 할인!
지난달 40대 여성분은 2주 만에 잠들게 되셨어요.
```

### 검수 결과 — 랜딩 오퍼 · 랜딩 페이지

| | 원문 | 무엇이 | 근거 |
|---|---|---|---|
| 🔴 | "20만원 상당을 무료로" | 금액 참조점 = 경제적 이익 제공 | 제27조 ③ |
| 🔴 | "선착순 20명 **특별 할인**" | 대상·기간·정가 없는 할인 | 제27조③ · 제56조②13호 |
| 🔴 | "4주면 불면이 **치료됩니다**" | 효과 보장 + 기간 약속 | 제56조②2호 |
| 🔴 | "40대 여성분은 2주 만에…" | 환자 치료경험담 | 제56조②2호 |
| ✅ | "블로그 개설 기념" | 명분이 금전이 아니라 **맥락**이다. 좋다 |

**🔴 가 네 개다. 이대로는 못 나간다.**

### 🔴 "20만원 상당의 맞춤 회복 리포트를 무료로 드립니다"

**왜** — 금액을 참조점으로 쓰면 「경제적 이익 제공」으로 읽힙니다. 제27조 제3항의
환자 유인은 **금품·할인·면제**를 전형으로 봅니다. **「무료」는 괜찮고 「20만원 상당」이 걸립니다.**

**A · 안전한 쪽**
> 진료실에서 30분씩 하던 설명을, 리포트로 정리해 드립니다.

**B · 세기를 살린 쪽**
> 평소 진료 시간에 다 못 드리던 이야기를, 이번엔 처음부터 끝까지 드립니다.

**무엇이 달라졌나** — 금액 대신 **시간과 밀도**로 값어치를 말합니다.
숫자를 쓰고 싶으시면 **금액이 아닌 숫자**(분량·문항 수·통 수)로 바꾸세요.
「A4 12장」 「5통에 나눠서」는 통과합니다.

### 🔴 "선착순 20명 특별 할인"

**왜** — **「선착순 20명」은 문제가 아닙니다.** 수량 한정은 유인이 아닙니다.
**「할인」**이 걸립니다.

**A** > 선착순 20명께는 제가 직접 코멘트를 답니다.
**B** > 20명까지만 받습니다. 그 안에 드시면 코멘트가 함께 갑니다.

### 🔴 "4주면 불면이 치료됩니다"

**왜** — 「치료」 + 기간 약속. 효과 보장으로 읽힙니다.

**A** > 4주 동안 주차별로 무엇을 볼지 함께 정합니다.
**B** > 4주가 지나면 자동으로 끝납니다. 그때는 혼자 하실 수 있게 되는 것이 목표입니다.

**무엇이 달라졌나** — 기간을 **결과의 약속**이 아니라 **프로그램의 길이**로 옮겼습니다.
이러면 통과합니다.

### 🔴 "지난달 40대 여성분은 2주 만에 잠들게 되셨어요"

**왜** — 환자 치료경험담. **가장 단호하게 막아야 하는 항목**입니다.
나이·성별을 지워도 **형태 자체가 금지 대상**이라 비식별화는 면죄부가 되지 않습니다.

**A** > 잠드는 시각보다 **일어나는 시각**을 먼저 고정하면 리듬이 앞당겨집니다.
**B** > 진료실에서 가장 자주 듣는 말이 「일찍 자려고 해도 안 된다」입니다. 그때는 뒤가 아니라 앞을 봅니다.

**무엇이 달라졌나** — **개인의 결과담**에서 **기전과 일반론**으로 옮겼습니다.
「진료실에서 자주 **듣습니다**」는 통과하고, 「진료실에서 자주 **좋아지십니다**」는 걸립니다.

### 이건 제가 판단하지 못합니다

- **사전심의 대상인지** — 매체 이용자 규모와 글의 성격에 따라 갈립니다.
  → 소속 협회의 의료광고심의위원회(의사·치과의사·한의사 각각)
- **실제 적용** — 같은 문장도 앞뒤 맥락과 이미지에 따라 달리 읽힙니다

### 한 줄

```
🔴 4개 · 🟡 0개 · ✅ 1개
가장 급한 것: 「20만원 상당」과 「특별 할인」 — 금액을 지우면 둘 다 풀립니다.
```

**고치신 뒤 한 번 더 돌려보세요.** 고치다가 새로 걸리는 일이 흔합니다.

## 예시 2 · 의료인 · 캐러셀 마지막 장

### 받은 문구

```
댓글에 「지도」 남겨주시면 회복 지도를 DM으로 보내드립니다.
해볼 만큼 해봤는데 나만 안 되는 것 같다면.
```

### 검수 결과

| | 원문 | 무엇이 | 근거 |
|---|---|---|---|
| ✅ | "댓글에 「지도」 남겨주시면" | 행동 하나 · 금액·효과 표현 없음 |
| ✅ | "해볼 만큼 해봤는데 나만 안 되는 것 같다면" | **상태 서술이지 효과 약속이 아니다** |
| 🟡 | "회복 지도" | 자료 이름은 괜찮으나, **그 자료 안에서** 효과 단정이 나오면 거기가 걸립니다 |

**🔴 없음. 이대로 나가도 됩니다.**

**다만 붙이면 더 안전해집니다.**
> 일반적인 생활 관리 자료이고, 진단이나 처방이 아닙니다.

**왜 권하나** — DM으로 자료를 받는 사람은 **의료 상담을 기대하고 들어옵니다.**
그 기대를 첫 줄에서 끊어두면 이후 상담 요청이 줄고, 요청이 와도 답하기 쉬워집니다.

> **과잉 검열하지 않는 예시다.** 🔴 를 못 찾았다고 억지로 만들지 않는다.
> 통과했으면 통과했다고 말하고, **왜 괜찮은지**를 남긴다.

## 예시 3 · 비의료인 · 필라테스 강사

### 받은 문구

```
거북목 치료 프로그램 — 무료 진단 받아보세요
원장님이 직접 봐드립니다
```

### 검수 결과 — 비의료인 기준

| | 원문 | 무엇이 | 근거 |
|---|---|---|---|
| 🔴 | "거북목 **치료**" | 「치료」는 의료행위를 지칭합니다 | 의료법 제27조 ① |
| 🔴 | "무료 **진단**" | 진단은 의료행위입니다 | 위와 같음 |
| 🔴 | "**원장님**이 직접" | 의료인 오인 호칭 | 위와 같음 |

**왜** — 비의료인은 **효과를 단정하지 않아도** 이 단어들 자체가 걸립니다.
실제로 의료행위를 하지 않아도 **「하는 것처럼 보이면」** 문제가 됩니다.

**대체안**

| 🔴 | ✅ |
|---|---|
| 거북목 치료 프로그램 | **목·어깨 자세 관리 프로그램** |
| 무료 진단 | **무료 자세 체크** / **자가 점검** |
| 원장님 | **○○ 코치** / **대표 강사** |

**붙이면 안전해집니다**
> 이 프로그램은 생활 습관과 자세에 관한 것이며, 의료 행위나 진단이 아닙니다.
> 통증이 이어지면 의료기관에서 진료받으시길 권합니다.

## 예시 4 · 의료인 · 스레드 글 — 광고/정보 관문부터

### 받은 글

```
시험 앞두고 잠 못 자는 수험생, 3주면 달라집니다.
저희는 약 없이 리듬으로 봅니다. 불면에서 해방되세요.
수험생은 이번 달 초진 무료 🎁 예약은 프로필 링크
```

### 먼저 — 광고인가 정보인가

「초진 무료」「예약은 프로필 링크」가 있어 **(다) 광고**다. 스레드 같은 SNS는 플랫폼 전체 이용자 수로 사전심의 대상 여부를 본다(복지부 2024.11.4).
→ 내용 규제 전부 + 심의 여부를 본다.

### 검수 결과 — 스레드 · 광고

| | 원문 | 무엇이 | 근거 |
|---|---|---|---|
| 🔴 | "수험생은 이번 달 초진 **무료**" | 진료를 무료로 + **특정군을 혜택으로 모집** | 제27조③ · 2판 환자유인 Q2 |
| 🔴 | "3주면 달라집니다" | 기간을 못 박은 효과 약속 | 제56조②2호 |
| 🔴 | "약 없이" | 타 치료와의 비교로 읽힌다 | 제56조②4호 |
| 🟡 | "불면에서 **해방**" | 완치를 돌려 말한 것으로 읽힐 여지. 조항이 직접 걸린다고 단정하긴 어렵다 | 제56조②2호·8호 |
| 🟡 | "예약은 프로필 링크" | 이 한 줄이 글을 광고로 만든다 | 복지부 2025.1.16 |
| ✅ | "시험 앞두고 잠 못 자는 수험생" | 대상 서술 자체는 문제 아님 | — |

### 🔴 "수험생은 이번 달 초진 무료"

**왜** — 진료를 무료로 주는 것은 금품 제공에 준하는 유인이고, 「수험생만」은 특정군을 혜택으로 모으는 구조입니다.
「수험생을 진료합니다」는 진료 안내이지만, 「수험생만 무료」는 다릅니다.

**A · 안전한 쪽**
> 수험생 진료 때 드리는 「시험 전 4주 수면 리듬표」를 정리해 두었습니다.

**B · 세기를 살린 쪽**
> 시험 앞두고 잠이 무너진 수험생을 위해, 진료실에서 30분씩 하던 설명을 한 장으로 만들었습니다.

**무엇이 달라졌나** — 무료인 것이 **진료**에서 **자료**로 바뀌었습니다. 값어치는 「30분」「한 장」으로 말합니다.

### 🔴 "3주면 달라집니다" · 🟡 "불면에서 해방"

**A** > 기상 시각부터 고정하면 리듬이 앞당겨지는 분이 많습니다.
**B** > 잠드는 시각을 붙잡는 대신, 일어나는 시각을 먼저 고정합니다. 리듬은 그쪽에서 먼저 움직입니다.

**무엇이 달라졌나** — 결과 약속이 **기전 설명**으로 바뀌었습니다. 「해방」은 갈림길입니다. 법 조항이 바로 걸리는 말은 아니지만, 심의를 낼 글이면 소속 협회 심의기준에서 걸릴 수 있으니 거기서 확인하세요.

### 정보 글로 남기는 길

「초진 무료」와 「예약은 프로필 링크」를 빼고, 기관명·「한방신경정신과 전문의」까지만 두면 **(나) 정보 + 면제 항목**이 된다. 그러면 심의 없이 올릴 수 있고, 남는 지적은 🟡 「해방」 하나뿐이다.

### 이건 제가 판단하지 못합니다
- 광고/정보의 **최종 판단** — 보건소별로 다를 수 있습니다
- 심의를 낼 거면 **글 전체**(본문·이미지·해시태그)를 한 건으로. 기준과 소요 기간은 소속 협회 심의위원회에 확인
- 오래된 글 — 민원이 오면 옛 글까지 함께 봅니다

```
🔴 3 · 🟡 2 · ✅ 1
가장 급한 것: 「초진 무료」를 자료로 바꾸고 링크를 뺄지 정한다
```

## 예시 5 · 의료인 · 카카오톡 채널 공지

### 받은 글

```
[○○한의원] 9월 수험생 집중관리 오픈! 상담 문의는 채널로 💬
지난 기수 학생들 성적이 올랐어요. 선착순 10명.
```

### 검수 결과 — 카카오톡 채널 메시지 · 광고

| | 원문 | 무엇이 | 근거 |
|---|---|---|---|
| 🔴 | (메시지 전체) **(광고) 표기·수신거부 안내 없음, 수신 동의 여부 미확인** | 광고성 정보 전송 규칙 — 문구보다 먼저 | 정보통신망법 제50조 |
| 🔴 | "지난 기수 학생들 성적이 올랐어요" | 치료경험담 + 효과 암시 | 제56조②2호 |
| 🟡 | "상담 문의는 채널로" | 채널에서 증상 상담이 오가면 그 대화가 진료처럼 보인다. 「예약 문의」로 좁히는 편이 안전 | — |
| ✅ | "선착순 10명" | 수량 한정 자체는 유인이 아니다 | 2판 환자유인 Q2 |

**가장 먼저** — 이 메시지를 받는 사람이 **광고성 정보 수신에 동의한 사람인지** 확인한다. 아니면 문구를 고쳐도 소용없다.
동의를 받았다면 앞에 `(광고)`, 끝에 무료수신거부 번호를 붙인다.

**"성적이 올랐어요" → A** > 시험 전 수면 리듬을 잡는 4주 진료를 9월에도 엽니다.
**→ B** > 시험이 다가올수록 무너지는 건 공부가 아니라 잠입니다. 그 4주를 같이 봅니다.

```
🔴 2 · 🟡 1 · ✅ 1
가장 급한 것: 수신 동의 확인, 그다음 「성적이 올랐어요」 삭제
```

## 톤 정리

| | |
|---|---|
| **원문을 인용한다** | 「전반적으로 위험합니다」는 아무 정보가 없다 |
| **조항을 적는다** | 근거가 없으면 안 고친다 |
| **🔴 를 아껴 쓴다** | 남발하면 스킬이 버려지고, 버려지면 아무것도 못 막는다 |
| **통과도 적는다** | 다음에 고치다가 잘 되던 걸 망가뜨리는 사고를 막는다 |
| **대체안 없이 끝내지 않는다** | 이게 이 스킬의 값어치다 |
